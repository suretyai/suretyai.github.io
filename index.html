01 · How it works

The loop is the product.

A frozen model does step one and stops. Fronesa runs all five, every week.

01

Decide

Every call returns a label and a confidence score in about 21 ms — plus a receipt: what was decided, how sure, and which model decided it.

02

Escalate

Low-confidence calls go to a human reviewer instead of a guess. You set the review budget — nothing fails silently.

03

Learn

Reviewer labels become training data. The model retrains weekly and only ships if it beats the current version on held-out data.

The five-step loop, repeating weekly. Learn is green — the step a frozen model skips.

03 · API reference

One endpoint.
One receipt.

Send content, get a decision. Audit any decision later by its receipt.

POST /decidebase URL provided at onboarding
# request
{ "text": "Free prizes, claim now!" }

# response — the decision receipt
{
  "decision":   "spam",
  "confidence": 0.95,
  "escalated":  false,
  "latency_ms": 14.1,
  "version":    "v1"
}
