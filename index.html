The loop is the product.

A frozen model does step one and stops. Fronesa runs all five, every week.

01

Decide

Every call returns a label and a confidence score — median 21 ms per decision — plus a receipt.

02

Escalate

Low-confidence calls go to a human reviewer instead of a guess. No model is right every time — that's why every decision carries its receipt.

03

Learn

Reviewer labels are logged as training data. Nothing is thrown away.

04

Retrain

The model retrains on the accumulated labels each week.

05

Gate

A new version ships only if it beats the current one on held-out data.

The five-step loop, repeating weekly. Learn is green — the step a frozen model skips.

Fair questions

Will this replace my reviewers?

Your reviewers keep their jobs — the loop runs on their labels.

Does my data train other customers' models?

Your labels never train anyone else's model.

How much work is the integration?

One endpoint. No SDK, no integration project.

One endpoint. One receipt.

Send content, get a decision.

POST /decidefronsea-api.onrender.com
# request
{ "text": "Free prizes, claim now!" }

# response — the decision receipt
{
  "decision":   "spam",
  "confidence": 0.95,
  "escalated":  false,
  "latency_ms": 14.1,
  "version":    "v1"
}

Your text is classified in memory and never stored — the API logs metadata only (timestamps, latency), never content.
