Fronesa · Content-moderation triage API

Decisions that learn.

Fronesa is a decision API for content-moderation triage. Every call returns a label, a confidence score, and a receipt you can audit. Edge cases route to your reviewers — their labels come back as training data, and the model retrains and re-gates on a weekly loop.

01 · How it works

The loop is the product.

  1. Decide

    The API classifies the content and returns a label with a confidence score — median 21 ms per decision. Every response includes a receipt: what was decided, how sure, and which model version decided it.

  2. Escalate

    Low-confidence calls route to a human reviewer instead of guessing. Escalation is budget-based — you set how much review you can afford — not a fixed threshold that quietly breaks.

  3. Learn

    Reviewer labels are logged as training data. Nothing is thrown away: a correction feeds the next training set instead of dying in a queue.

  4. Retrain

    The model retrains on the accumulated labels each week. Corrected labels retrain your own model version by default — they never feed anyone else's without written consent.

  5. Gate

    A new version ships only if it beats the current one on held-out data it never trained on. If it doesn't beat it, it doesn't ship.

03 · API reference

One endpoint.
One receipt.

Send content, get a decision. The response always includes the receipt — decision id, label, confidence, whether a human was involved, and the model version. Audit any decision later by its id.
