Fronesa — legal

What we collect, and what we don’t.

Short version: this site barely collects anything. The pilot API processes what you send it and nothing more. We never sell data — there isn’t much to sell.

LAST UPDATED — OCTOBER 2026

1. This website

The site is a set of static pages. We set no cookies ourselves, run no analytics of our own, and have no accounts, no sign-ups, and no tracking pixels here.

Two honest caveats:

  • The pages are hosted on GitHub Pages, which as the hosting provider may log standard technical data (such as IP addresses and user agents) under GitHub’s own policies. We don’t see or use those logs.
  • The demo page runs entirely in your browser — its outputs are pre-computed. Nothing you click or select on the demo is sent to us.

2. The pilot API

If you use the pilot API, we process the texts you send in order to return decisions. That’s the product working as intended.

  • Request texts are retained only as long as needed to operate the pilot (debugging, measuring quality, running the learning loop you asked for).
  • We never sell your data, and we don’t share it with third parties except as required by law.
  • We do not train shared models on your data without your written consent — see data handling.

3. Email

If you write to surety.ai@proton.me, we keep the correspondence so we can reply and remember the conversation. We don’t add you to any mailing list — there isn’t one.

4. Your rights

Whatever we hold about you, you can ask to see it or delete it. Write to surety.ai@proton.me and we’ll handle it — a human reads that inbox.

Plain truth: we’re a pre-revenue pilot, not a data company. The most valuable thing we own is the learning loop mechanism — not your texts. Our incentives point toward holding as little of your data as possible.

5. Changes

If this policy changes, we’ll update the date above. Material changes will be noted plainly — not buried.
