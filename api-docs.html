spec Fronesa Decision API v6 OpenAPI 3.0.3
The escalation contract. Every decision response carries an escalated boolean. When escalated is true, the model is telling you it is not confident enough to decide — route the case to human review and never auto-act on it. This is the product's core promise; the API reference below treats it as load-bearing.
Endpoints
    Authentication. Protected endpoints take a Bearer API key: Authorization: Bearer <key>. A missing or invalid key returns 401 with code UNAUTHORIZED. Rate limit: 100 requests/minute per key — 429 with a Retry-After header when exceeded. A batch of N texts counts as N requests. Every response carries an X-Request-ID header for support. Request bodies are capped at 64 KB for /decide and 512 KB for /decide/batch (413 beyond that). Your key is kept in this page's memory only — it is never stored, logged, or sent anywhere except the API host you choose below.

    Quickstart

    First call in ten seconds.

    bashreplace $FRONESA_KEY
    curl -X POST https://fronsea-api.onrender.com/decide \
  -H "Authorization: Bearer $FRONESA_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "Free prizes, claim now!"}'

    A typical response: {"decision": "spam", "confidence": 0.95, "escalated": false, "model": "spam", "version": "spam-v1", "latency_ms": 1.2}. If escalated comes back true, send the text to a human — do not auto-act.
