Integration guide

Discord bot moderation

Filter spam and scam messages in a Discord server with the Fronesa decision API and discord.py. Confident spam gets deleted; uncertain messages go to your mods — never auto-banned.

The problem

Public Discord servers attract crypto-scam DMs-by-proxy, phishing links, and spam floods. Human mods can't watch every channel at 3am. A keyword list either misses everything or bans your most active members.

The code

bot.py27 lines
import os
import discord
from fronesa import Client, APIError

fronesa = Client(api_key=os.environ["FRONESA_API_KEY"])
MOD_CHANNEL_ID = 123456789  # your #mod-review channel

intents = discord.Intents.default()
intents.message_content = True
bot = discord.Client(intents=intents)

@bot.event
async def on_message(message):
    if message.author.bot or not message.content.strip():
        return
    try:
        result = fronesa.decide(message.content)
    except APIError:
        return  # API down: let the message through, mods handle it
    if result.escalated:
        mod = bot.get_channel(MOD_CHANNEL_ID)
        await mod.send(f"Review: {message.jump_url} "
                       f"(confidence {result.confidence:.2f})")
    elif result.decision == "spam":
        await message.delete()
        await message.channel.send(
            f"{message.author.mention}, that looked like spam and was removed.",
            delete_after=10)

bot.run(os.environ["DISCORD_TOKEN"])
Note on async: decide() is synchronous and blocks the event loop for a few milliseconds per call on a warm container. For busy servers, call it in an executor or use the SDK's AsyncClient (same decide() API, await-able). Cold-start caveat: the free tier sleeps after ~15 idle minutes, and the first call after idle can block for up to ~90 s (or trip the SDK's 10 s default timeout) — warm the service or run the first call off the event loop.

What escalation looks like here

API saysBot doesWhy
spam, confidentDeletes the message, logs itLab-measured zero false positives on spam — safe to act
ham, confidentNothing — message staysNo reason to touch it
escalatedPosts a link + confidence score to #mod-reviewThe model isn't sure — a human decides, never auto-ban
Honest scope: this guide filters spam/scam text — that's what the production model is trained for (lab accuracy 0.9875 on spam vs. legitimate messages). It is not a harassment or hate-speech detector. Don't promise your members coverage it doesn't have.

SDK reference: Client(api_key, ...) · client.decide(text) → Decision(decision, confidence, escalated, version) · exceptions: APIError and subclasses.
