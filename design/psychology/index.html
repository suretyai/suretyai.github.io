Every visual rule in the guidelines rests on a mechanism in the human brain. This page collects them: the ideas, the writing styles, the musts and mustn'ts — everything we should do, and why.

01 · Mechanisms

Twelve ideas that run the system■

When two rules conflict, the deeper mechanism wins.

1. Processing fluency → truth

Ease of processing is misattributed as truth, quality, and trust. A clean page is literally easier to believe. Every unnecessary element taxes the believability of everything else.

Reber, Schwarz & Winkielman, 2004

2. The 50ms snap judgment

Visual-appeal judgments form in 50 milliseconds and predict later credibility ratings. The hero must read as intentional — prototypical, low-complexity — before a word is read.

Lindgaard et al.

3. Costly signaling

Checkable claims are believable because being wrong is punishable. Hype adjectives are cheap — anyone can claim them, so the brain discounts them. Specificity is a trust technology.

Signaling theory; Stanford credibility

4. The precision effect

Precise numbers are judged more credible than round ones — the brain infers measurement behind them. But false precision destroys more trust than vagueness. Precision is earned, never invented.

Berkeley CMR review, 2024

5. Von Restorff (isolation)

The one different item is noticed and remembered. A single green accent in a monochrome field pops; every added hue halves the effect until color means nothing.

Hedwig von Restorff, 1933

6. Gestalt proximity

Grouping by distance outranks color, size, and shape. Space between groups must be ≥2× space within groups — the most violated, most visible spacing law.

Wertheimer; NN/g formulation

7. Figure–ground

The brain holds one figure–ground assignment at a time. Two competing focal elements force constant re-decision — which reads as chaos before any conscious judgment forms.

Gestalt psychology

8. Layer-cake scanning

Fixations cluster on headings; body text is opt-in. The F-pattern is what happens with no formatting to lean on — a failure state, not a target. Headings must summarize.

NN/g eyetracking, 500+ participants

9. Hick's law

Decision time grows logarithmically with the number of choices. One primary action per viewport; disclose the rest progressively.

Hick, 1952

10. Cognitive load

Extraneous load (bad design) steals capacity from germane load (your argument). Every element must justify the working-memory slot it occupies. Decoration isn't neutral — it consumes.

Sweller

11. Calibrated trust

The goal is appropriate reliance, not maximum trust. Uncertainty shown honestly and continuously; binary certainty manufactures overreliance. "Escalated" proves the system knows its limits.

Lee & See; Google PAIR

12. Whitespace value

Identical products surrounded by whitespace rated 7.8 vs 5.2 on quality, +37% price estimates. Whitespace is expensive because it represents choice — deliberate non-filling.

Pracejus, Olsen & O'Guinn, 2006

02 · Writing styles

Decisions that learn■

The brand sounds like the tagline reads. Every style below is a trust mechanism, not a preference.

The five styles

StyleRuleExample
HonestState what was measured, with number and method. No claim without a source."0.38% loop error, seed 7, n=2,400."
TechnicalConcrete nouns, real mechanisms. For engineers, never abstraction fog."The loop re-labels from disagreements."
PlainShort sentences. No ceremony. Outcome-first."Your labels train only your model."
PreciseExact numbers where measured. Context always: what, vs what, how."0.38% vs 1.71% · 10% judge noise."
RestrainedZero hype adjectives. Let the numbers carry the weight."Measured in public." (not "revolutionary")

Banned language

Neverrevolutionary · game-changing · disruptive · cutting-edge · next-gen · world-class · best-in-class · AI-powered (as hype)
NeverInvented multipliers (4.5×, 20×) · unqualified "zero false positives" · any revenue/customer/certification claim · "your data may be used to improve our models"

Structure

  • Headlines ≤ 12 words — the whole proposition in one fixation sweep.
  • Ledes ≤ 140 characters — framing, not informing.
  • Key information first — the first 2–3 words carry the claim (scan rail).
  • One idea per paragraph. One idea per viewport. One idea per email.
  • Numbers as nouns — "0.38% loop error" not "our error rate is very low at 0.38%."

03 · Musts

Everything we should do■

Musts
  • Show the number with its method, every time.
  • Keep one green per surface; one accent per viewport doing real work.
  • Left-align everything; lock body measure at 65ch.
  • Make the primary action unmistakable — verb-first, 44px, green.
  • Admit uncertainty: show confidence, show the escalate path.
  • Keep the escalation path visible — uncertain verdicts route to the larger model. Supervision is trust architecture.
  • Fix typos before adding features. Small errors generalize.
  • Alternate air and evidence: every whitespace chapter neighbors a proof chapter.
  • Set claims in authority type (Fraunces). Never casual faces for facts.
  • Measure overflow at 320/390/768/1024/1440 before every ship.
  • Write alt text describing informational content, not appearance.
  • Make every page fully usable with zero motion.

04 · Mustn'ts

Everything we never do■

Mustn'ts
  • Never use transparency, glass, glow, gradients, or shadows as brand language.
  • Never center body text or headlines. Never justify text.
  • Never round the decision square. Never recolor it. Never detach it.
  • Never retype the wordmark — always the SVG.
  • Never add a third expressive typeface. Never set headlines in sans.
  • Never show a number without: what, vs what, how measured.
  • Never round a measured number. Never invent precision.
  • Never use hype adjectives. Never imply more than the evidence supports.
  • Never hide the escalation path. Never present binary certainty.
  • Never ship horizontal overflow. Never ship a typo. Never ship lorem ipsum.
  • Never use stock photography of fake customers. Never fake testimonials.
  • Never let decoration consume the working memory the argument needs.
