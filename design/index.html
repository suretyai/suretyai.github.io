§0–1 · Foundation

Five principles, strictly held■

Apple is the teacher of clarity — strict scales, named materials, rules over vibes. The language itself is ours. What makes it owned:

01

Light is proof

Luminance never decorates. Glow and specular light appear only where the product is genuinely working — a decision rendered, the loop learning, a live state. Never as ornament.

02

The decision square

The D1 wordmark's green square recurs as the system's signature motif — terminal punctuation on headlines, verdict markers, the Learn node. Square in a world of round.

03

The verdict moment

No other design language centers a live decision instrument. Our hero component is the demo console; the language is built around the instant a decision lands.

04

Green monochrome luminance

Our glow is green-only, always. Never rainbow, never iridescent, never blue-purple. One hue, full conviction.

05

Bold is structural

Weight comes from the type scale, spacing rhythm, and material — not from shadows, outlines, or effects stacked onto timid layout.

Strict rules

  • Glass refracts, never frosts. Our glass bends light at its edges. backdrop-filter: blur() is banned in every context, no exceptions.
  • Every radius is from the scale. No arbitrary border-radius values. If it isn't in §6, it doesn't ship.
  • One green per surface. Light surface → Decision Green #0F5132. Dark surface → Signal Green #4A9E6B. Never both on one surface.

Strict rules

  • Body text: --ink-900 on --paper-0 (AAA). Reversed: --paper-0 on --ink-900.
  • Green text only at ≥18px or weight ≥700. Never body copy. Never green-on-green.
  • Forbidden pairs: Green on Ink · Bright on Paper · Ink on Green · Paper on Green.
  • Glow colors: green-family only. No white glow, no colored glow, ever.
  • Muted text (--ink-500): labels, captions, metadata — never claims, never headlines.

Strict type rules

  • Display (Fraunces 900) reserved for: page hero, section headlines, decision verdicts. Maximum one --text-display per viewport.
  • UI sans for everything functional: buttons, inputs, nav, labels, body copy.
  • Mono for instrument readings: latency, confidence, timestamps, code, eyebrow kickers.
  • The green square period. Display headlines and H2s close with ■ instead of a period. One per headline, never in body copy.
  • Verdict text — a rendered decision — is Fraunces 900, green, with glow. The only sanctioned glowing text.
  • Letter-spacing: -.015em display · 0 UI · .14em uppercase eyebrows. Nothing else.
  • text-wrap: balance on all display type. No orphans, no manual <br> in headlines.

§5 · Materials

Verdict Glass■

The material decisions are made of. Real WebGL refraction — light bends at the edges, specular catches the bevel. The demos below are live: drag the orb.

DRAG
Verdict Glass

ENGINE

The law

  • Glass refracts, never frosts. Displacement + specular edge. backdrop-filter: blur() is banned everywhere, no exceptions.
  • Permitted: backdrop-filter: saturate() / brightness() — they enliven without frosting.
  • Glass is for: floating nav, demo console, verdict receipts, primary CTAs, modal sheets. Maximum 3 glass surfaces per viewport.
  • Glass is NEVER for: body text containers, long-form reading, footers, full-page backgrounds.
  • Glass minimum radius: --r-16. Text on glass must pass WCAG AA.
  • The nav pill above uses the exact production material — defaults untouched.

§6 · Radius

Seven radii, no others■

No arbitrary border-radius values. If it isn't here, it doesn't ship. Nesting rule: inner radius = outer − 8.

--r-4 · square max
focus rings, tags

--r-8
chips, toggles

--r-12
buttons, inputs

--r-16
glass minimum

--r-24
console, panels

--r-32
hero, modals

--r-full
pills, nav

  • The decision square is square. The brand's green square takes --r-4 maximum — never round, never pill.
  • Focus rings follow the element's radius + 4px offset ring.

§7 · Light & glow

Light is proof■

Glow appears only where the product is working. Press the button — the verdict lands, the light fires. Before that, quiet.

Glow appears — exhaustive list

  • Verdict rendered — decision word, --glow-normal
  • Learning active — may breathe (2.4s, the only animated glow)
  • Live connection — --glow-whisper
  • Hover intent — primary button hover
  • Focus — solid ring, never glow

Glow never appears

  • Body text, headlines (except verdicts), static icons
  • More than one glowing element per section
  • As a permanent state on a static element
  • In any color other than green

§10 · Motion

Springs, not tweens■

Liquid elements move on real spring physics — k=150, c=12. Stretch with velocity, smear mid-flight, settle to perfect clarity. Tap the tabs.

Durations

--dur-micro: 120ms
--dur-base: 200ms
--dur-emphasis: 320ms
Nothing longer. Ever.

Easing

--ease-out: cubic-bezier(.2,.7,.2,1)
--ease-settle: cubic-bezier(.3,1.4,.4,1)
Slight overshoot on emphasis only. Never bouncy.

What never animates

  • Body text. Layout in response to scroll. Glow (except the 2.4s learning breath).
  • Anything on an infinite loop — except loading spinners and the learning breath.
  • prefers-reduced-motion: reduce → all motion becomes instant. The page must be fully usable with zero motion.

The verdict reveal

Fade + 8px rise, 200ms. The glow fires exactly when the decision lands — see §7.

Compliance checklist

  • Every radius, spacing, color, and duration is a token from this document.
  • backdrop-filter: blur() appears nowhere (grep it — zero hits).
  • Glow appears only at §7 states, max one per section, green only.
  • Glass surfaces ≤ 3 per viewport; glass never holds body text.
  • One green per surface; forbidden color pairs absent.
  • Display type: one --text-display per viewport max; headlines end with the green square.
  • Zero horizontal overflow at 320 / 390 / 768 / 1024 / 1440 (measured, not eyeballed).
  • Keyboard: all interactive elements reachable, focus rings visible, 44px targets.
  • prefers-reduced-motion: page fully usable, no motion.
  • No invented claims, no AI-startup diction, numbers traceable to lab artifacts.
