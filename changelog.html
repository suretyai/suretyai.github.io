Every change, dated and plain.

What shipped, when, and what it means for you. Dated entries are live; Unreleased is built but not yet public. No hype, no adjectives — just the record.

Unreleased

In progress

Added

  • fronesa Python SDK 0.1.0 — packaged and tested, pending PyPI publication.
  • Developer Terms, Security Policy, and a Getting Started guide — built, pending publish.
  • Public README for the suretyai/fronesa repository — published.

Changed

  • POST /review input hardening — reviewer_id, decision_id capped at 256 chars, customer_id at 128; reviewed_at must be ISO-8601. Oversized or malformed values get 400, not silent truncation.
  • Error responses no longer leak internals — server exception details replaced with generic messages (details stay in server logs).
  • Try-it demo page: five honesty disclosures added — the demo page now says what it shows:
    • the demo model is not the production model;
    • calibration limits stated alongside confidence scores;
    • the human-review loop described as a pilot flow, not present-tense fact;
    • what submitted text is retained, and for how long;
    • that example inputs are curated samples.
    All five verified present on the page after the fix.
  • API reference footer cleaned up — the last stray Developer Terms link was removed from the api-docs.html footer. All 20 site pages now have the same footer links.

1.1.0

2026-10-05

Added

  • latency_ms in every POST /decide response — measure your own round-trips.
  • Legal pages — Terms of Service, Privacy Policy, and Data Handling, linked in the site footer.

Changed

  • Benchmarks page rebuilt — lab-measured numbers only, with honest limitations stated (weak TweetEval sentiment results shown, not hidden).

1.0.0

2026-10-04

Added

  • Public launch of the Fronesa decision API at https://fronsea-api.onrender.com.
    • POST /decide — send text, get back decision, confidence, escalated, version.
    • Bearer-key authentication (401 without a valid key).
    • GET /health, GET /version.
  • Public site at suretyai.github.io/fronesa with a live demo page.

Security

  • 100 requests/minute per-key rate limiting (429 + Retry-After).
  • Fail-closed startup — the API refuses to boot if the model self-check fails.
  • 64 KB request body cap; request IDs on every response; uniform JSON errors; no client-facing stack traces.
