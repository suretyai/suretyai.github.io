Honest eval · Part 22

What 270 paired labels actually buys.

TIGHTEN-FIRST says no retraining on current skewed data. The condition for revisiting: 270 new paired labels — 90 phishing, 180 legitimate. Here's what that number actually means.

Fronesa engineering October 6, 2026 5 min read

The number

TIGHTEN-FIRST — the decision recorded in the CEO retrain memo (2026-10-06) — says: no retraining on the current skewed data. The condition for revisiting is a clean collection target: 270 new paired labels — 90 phishing, 180 legitimate.

This post explains what that number actually means. A paired label is one item reviewed twice: once by the machine (the TF-IDF v1 decision plus its confidence), once by a human reviewer through the protocol part 21 described, with the verdict and the disagreement recorded in the review ledger. The pair is the unit of trust. A label without its machine counterpart teaches nothing; a machine decision without its human counterpart is unverified.

Why the split is 90 / 180

Phishing is the scarce class. The measured phishing corpora are the ones where calibration was weakest (ECE ~0.211 OOD vs ~0.046 in-distribution SMS), so the plan over-weights phishing relative to its natural frequency: 90 phishing pairs against 180 legitimate ones. The legitimate half is the guardrail — the two false positives on the v4 HELDOUT gate are the number a retrain must not worsen. The 180 exist to prove the retrain learned to catch more without learning to suspect more.

Where the count stands

Honestly: zero paired labels collected so far. The reviewer instrument exists on paper, the ledger schema exists, the protocol exists. The pairs do not. Publishing the zero is the point — a collection program that counts only when it has something is a program that cannot be audited.

It does not buy a model. It does not buy a guarantee. It buys the right to run an experiment whose result can be believed.

What collection unlocks, in order

  1. A real phishing-aware promotion gate. Today's gate measures SMS only; phishing is invisible to it. 90 phishing pairs are the minimum that makes a phishing promotion gate computable.
  2. A retrain that can be judged. A retrain without before/after on the same paired set is a story, not a measurement. The 270 define the set.
  3. A reviewer baseline. The first 270 verdicts are also the first measure of reviewer agreement — the disagreement rate is a product input, not a failure mode.

What 270 does not buy

It does not buy a model. It does not buy a guarantee. It buys the right to run an experiment whose result can be believed. If the retrain at 270 pairs shows recall improving with false positives at or below 2, the program continues. If it doesn't, the program stops — and that outcome gets its own post, with the same honest number.

The lesson

A collection program that counts only when it has something is a program that cannot be audited. Publish the zero.

Chain of custody

Pre-publish blockers

  1. Legal spot-check of all numeric claims (paired-label plan, FP counts, retrain outcome).
  2. Collection count at publish time must be freshly verified — the draft states 0 collected; do not publish a stale number if collection has started.
  3. No entity, no payment processor: do not present collection as a funded program or paid reviewer pool.
  4. Braa review required on any line that implies a timeline for retraining.
  5. Do not attach this piece to any marketing claim about future accuracy gains.
